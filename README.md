# Clarity

A calm, visual knowledge map for working through questions, known facts, and possible meanings without confusing one for another.

## First version

- Topic and story spaces
- Question, Knowledge, and Meaning cards
- Explicit first-hand, shared, or hypothesis labels
- Editable and rejectable interpretations
- Connect and disconnect cards
- Quick capture for bulk thought-dumps
- Gentle force-directed movement with pan and zoom
- Browser-local storage with private JSON export/import

## Run locally

```bash
npm install
npm run dev
```

## Privacy

This first version has no account or backend. Map data stays in the current browser unless it is explicitly exported. Before deploying for another person, decide whether the initial map should be empty or contain carefully reviewed seed content; never encode sensitive personal interpretations as facts.
